# Supermercado Campos

Site institucional do Supermercado Campos (R. Codornas, 15 – Costa e Silva, Joinville/SC).

Página única em HTML/CSS/JS, sem build e sem dependências além das fontes do Google Fonts.

- Hero animado com destaques das avaliações
- Status "aberto/fechado" calculado ao vivo no fuso de Joinville
- Setores, números, avaliações, horários, endereço e rotas
- Responsivo, tema claro/escuro, respeita `prefers-reduced-motion`

## Rodar

Abra `index.html` no navegador ou sirva a pasta:

```sh
python3 -m http.server 8080
```
